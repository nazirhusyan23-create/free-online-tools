Camel Case, Snake Case, and Kebab Case Explained for Non-Coders

These naming conventions look like coding jargon, but understanding them helps anyone working with filenames, URLs, or spreadsheets. Here's a plain-English breakdown.

+

You don't need to write code to run into camelCase, snake_case, or kebab-case. They show up in spreadsheet column headers, URL slugs, file names, and even social media handles — and each has a distinct look and purpose.

The three formats, side by side

camelCase

The first word is lowercase and each new word starts with a capital letter, with no spaces — like firstName. Common in programming variable names.

snake_case

All lowercase, with underscores replacing spaces — like first_name. Popular in databases and Python code because it's easy to read at a glance.

kebab-case

All lowercase, with hyphens replacing spaces — like first-name. This is the standard for URL slugs because search engines and browsers treat hyphens as word separators, unlike underscores.

Why it's worth knowing even if you don't code

If you're naming a spreadsheet column, a file, or a blog post URL, picking the right convention keeps things consistent and machine-readable. A case converter can instantly reformat a phrase into any of these styles, saving you from manually retyping underscores and hyphens by hand.

A rough rule of thumb

Are QR Codes Safe? What Users Should Check Before Scanning

QR codes themselves aren't inherently dangerous, but they can be used to disguise malicious links. Here's what to check before you scan.

+

A QR code is just an encoded piece of text or a URL — it isn't inherently dangerous, but exactly because it hides the destination visually, it's become a tool some scammers use to disguise a malicious link.

What to watch for

  • A sticker placed over an existing, legitimate QR code — a common tactic in parking payment scams
  • A shortened or unfamiliar-looking URL preview after scanning, before you tap to open it
  • Codes in unsolicited emails or texts asking you to scan for an urgent action

A simple safety habit

Most phone cameras show a URL preview before actually opening the link — always read it before tapping through, the same way you'd hover over a suspicious email link before clicking.

When generating your own codes

If you're a business owner creating codes for customers, choose a reputable generator and consider adding a short caption near the code stating exactly what it links to, which builds trust and helps your customers verify it's legitimate before scanning.
